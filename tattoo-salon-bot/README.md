# Бот тату-салона: график работы и график затрат

Telegram-бот, который:

- **составляет график работы мастеров** на месяц одной кнопкой: поровну, с учётом выходных, рабочих дней салона и лимита «не больше N дней подряд»;
- **ведёт расходы**: пишете «3500 краска», выбираете категорию, и расход записан;
- **держит график затрат (платежей)**: аренда, коммуналка, реклама, закупки. Показывает, что и когда платить, и напоминает заранее;
- присылает **отчёты**: по категориям, сравнение с прошлым месяцем, диаграмму и выгрузку в Excel;
- даёт **мастерам** свой вход: они видят свои смены, просят выходные и получают напоминание накануне смены.

## Быстрый старт

1. Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируйте токен.
2. Скопируйте `.env.example` в `.env` и вставьте токен в `BOT_TOKEN`.
3. Запустите бота одним из способов.

**Docker (рекомендуется для сервера):**

```bash
docker compose up -d --build
```

**Python 3.11+:**

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m salon_bot
```

4. Напишите боту `/start`. Первый, кто это сделает, станет владельцем (или заранее укажите свой ID в `ADMIN_IDS`; узнать ID можно командой `/id`).

### Без компьютера: хостинг Amvera

Всё делается в браузере телефона или планшета; Amvera принимает оплату российскими картами.

1. Положите код бота в отдельный репозиторий GitHub (Dockerfile должен лежать в корне).
2. Зарегистрируйтесь на [amvera.ru](https://amvera.ru), нажмите «Создать проект» → «Приложение», выберите тариф «Начальный» (на «Пробном» боту не хватит памяти).
3. Привяжите репозиторий GitHub во вкладке «Репозиторий» (понадобится токен GitHub с доступом `repo`).
4. В «Переменных» добавьте секрет `BOT_TOKEN`, при необходимости `TZ_NAME` и `ADMIN_IDS`.
5. Запустите сборку. База хранится в постоянной папке `/data` и не пропадает при пересборке.

## Первые шаги владельца

1. **👥 Мастера → ➕ Добавить мастеров**: пришлите имена, каждое с новой строки.
2. **⚙️ Настройки**: рабочие дни салона, часы смены (по умолчанию 11–21), сколько мастеров в смену, максимум дней подряд, время напоминаний.
3. **📅 График работы → ⚡ Составить**: бот распределит смены на месяц и пришлёт картинку графика.
4. **🗓 Платежи → ➕ Новый платёж**: добавьте регулярные траты (аренда 1-го числа, интернет 15-го, уборка каждую пятницу и т. п.).
5. В карточке мастера нажмите **🔗 Пригласить в бота** и перешлите ссылку мастеру.

## Как вводить расходы

Просто напишите боту сообщение, затем выберите категорию:

| Сообщение             | Что запишется                                 |
| --------------------- | --------------------------------------------- |
| `3500 краска Dynamic` | 3 500 ₽ сегодня, комментарий «краска Dynamic» |
| `вчера 1200 перчатки` | 1 200 ₽ вчерашним числом                      |
| `05.10 60 000 аренда` | 60 000 ₽ за 5 октября                         |
| `2к иглы`             | 2 000 ₽                                       |

Категории: аренда, расходники, оборудование, коммуналка и связь, зарплата, реклама, налоги, прочее.
Ошибочную запись можно удалить кнопкой «🗑 Отменить» или в «🧾 Последние записи».

## Что видит мастер

- **📅 Мои смены**: смены на 30 дней вперёд.
- **📆 График салона**: кто работает на неделе, картинка на месяц.
- **🌴 Хочу выходной**: даты вида `25.10`, `25.10, 27.10` или `01.11-05.11`. Владелец получает уведомление, а если на эти дни уже стоят смены, бот подскажет, какие дни поправить.

## Напоминания

Каждый день в выбранное время (по умолчанию 10:00, часовой пояс задаётся в `TZ_NAME`):

- владельцу приходит список завтрашних смен и платежей: просроченных и тех, что подходят в ближайшие 3 дня;
- мастерам, подключённым к боту, приходит напоминание о завтрашней смене.

## Как составляется график

Для каждого рабочего дня бот берёт нужное число свободных мастеров, у которых пока меньше всего смен. Выходные дни (субботу и воскресенье) он распределяет отдельно, чтобы они тоже доставались всем поровну. Мастер не ставится в дни, когда просил выходной, и не работает больше заданного числа дней подряд, с учётом смен в конце прошлого месяца. Если людей не хватает, бот честно об этом скажет и отметит такие дни знаком «!» на картинке.

Для текущего месяца график пересоставляется только с сегодняшнего дня: прошедшие смены не трогаются. Любой день можно поправить вручную: кнопки «✏️» под недельным графиком позволяют поставить или снять смену и поменять часы.

## Данные

Всё хранится в одном файле SQLite: `/data/salon.db` в Docker (на Amvera — в разделе «Данные») или `data/salon.db` при запуске без Docker. Для резервной копии достаточно скопировать этот файл.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты проверяют разбор дат и сумм, алгоритм графика, расчёт платежей, а также полный сценарий работы: от `/start` до напоминаний, через настоящий диспетчер aiogram с подменённым Telegram API.

## Структура

```
salon_bot/
  __main__.py      запуск: python -m salon_bot
  app.py           сборка диспетчера и роутеров
  handlers/        диалоги: график, мастера, расходы, платежи, настройки
  planner.py       алгоритм составления графика
  payments.py      расчёт дат регулярных платежей
  parsing.py       разбор дат, сумм и часов из текста
  charts.py        картинки графика и расходов
  excel.py         выгрузки в Excel
  reminders.py     ежедневные напоминания
  db.py            хранилище SQLite
```
